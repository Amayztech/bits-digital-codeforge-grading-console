# Bug Fix Log — BITS Digital CodeForge V1.0

Every entry below was reproduced in a real Chromium instance against the supplied
starter console before being fixed. The reproduction harness is preserved in the
repository:

- `tests/recon/starter-probe.js` — 33 scenarios against the original file
- `tests/recon/starter-probe2.js` — instrumented probes (CSV payload capture, canvas geometry)
- `artifacts/recon/starter-probe.json` — recorded output of the first harness
- `tests/fixtures/build.js` — the 25-workbook adversarial corpus

The original console is kept verbatim at
`starter-reference/BITS_Digital_CodeForge_Challenge.ORIGINAL.html` so every claim
below can be re-checked.

Bugs are grouped by the area in which they were found. Where the challenge brief
and the starter implementation disagreed, the disagreement is recorded as its own
entry rather than quietly resolved.

brief, the brief's own worked examples and the starter implementation disagree.
