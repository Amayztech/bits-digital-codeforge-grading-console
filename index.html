What this workspace checks

Required columns are mapped, and the sheet that actually holds the marks is found even if it is not the first one.
Every mark is a whole number from 0 to 100. Anything else is listed with its row number and never guessed at.
Duplicate and blank BITS IDs are caught per course, so one student cannot be graded twice.
Every mark from 0 to 100 is guaranteed exactly one grade, so no student can silently vanish from the export.

Instructor name (top right) is printed on the report and written into both exports.
